---
title: Gen - Mode 각각의 의미
---

Mode는 **"자식 제너레이터를 부모 스파인 위에 어떤 규칙으로 배치할 것인가"** 를 결정합니다.

---

**Classic** SpeedTree 구버전 방식의 기본 배치. Frequency 값으로 밀도를 조절하며 랜덤하게 분포. 가장 단순하고 직관적이지만 제어 정밀도가 낮음.

**Proportional** 부모 스파인 길이에 **비례**해서 배치 수가 결정됨. 부모가 길수록 더 많이 생성. 긴 가지에는 많이, 짧은 가지에는 적게 자동 조절되어 자연스러운 분포를 만들 때 유용.

**Proportional steps** Proportional과 동일하지만 배치 위치가 **균등 간격**으로 고정됨. 랜덤 없이 정렬된 느낌. 규칙적인 패턴이 필요한 식생(선인장 가시 등)에 적합.

**Absolute** 부모 길이에 상관없이 **고정된 수(Count)** 만큼 배치. 부모가 길든 짧든 항상 같은 개수. 꽃잎처럼 "무조건 5개"가 필요할 때 사용.

**Absolute steps** Absolute와 동일하게 고정 수를 배치하되, 위치가 **균등 간격**으로 정렬됨. Absolute + 정렬 버전.

**Phyllotaxy** 식물학의 **엽서(葉序) 패턴** 구현. 실제 식물이 잎을 배치하는 황금각(137.5°) 나선 규칙을 따름. 해바라기 씨앗 배열, 소나무 구과처럼 자연에서 나타나는 나선형 배치가 필요할 때 사용.

**Interval** ✓ (현재 선택) 지정한 **간격(Frequency)** 마다 하나씩 배치. 앞서 설명한 것처럼 First/Last 범위 안에서 일정 간격으로 규칙적 배치. 가지처럼 줄기를 따라 일정 간격으로 나오는 구조에 적합.

**Bifurcation** Y자 **분기(갈라짐)** 전용 모드. 부모 스파인의 끝에서 두 갈래로 나뉘는 형태를 만들 때 사용. 나무 가지가 끝에서 두 개로 갈라지는 자연스러운 분기 표현.

**Flood** 부모 표면 **전체에 균일하게 채움**. 이끼, 표면을 덮는 작은 식생처럼 빈 곳 없이 전체를 커버해야 할 때 사용.

**Parent** 부모 제너레이터의 배치 위치를 **그대로 상속**. 부모가 있는 위치에 자식도 동일하게 생성. 복합 구조를 만들 때 부모-자식이 항상 같은 위치에 있어야 할 경우 사용.

---

#### 한눈에 요약

```
랜덤 분포가 필요   → Classic / Proportional
정렬된 분포가 필요  → Proportional steps / Absolute steps
고정 개수가 필요   → Absolute / Absolute steps
자연 나선 패턴     → Phyllotaxy
일정 간격 배치     → Interval
Y자 분기          → Bifurcation
표면 전체 채움     → Flood
부모 위치 그대로   → Parent
```
