---
title: Frond vs Leaf 차이
---

핵심 한 줄로 먼저 말하면:

> **Leaf는 점(Point)에서 나오고, Frond는 선(Spine)을 따라 펼쳐진다**

---

### 구조적 차이

**Leaf** 배치 지점 하나에서 **단일 면**이 나옵니다. 부모 스파인 위의 각 포인트에서 독립적인 평면 하나씩 생성.

```
Branch ────●────●────●────●
           │    │    │    │
           🍃   🍃   🍃   🍃   ← 각 점에서 독립된 잎 1장씩
```

**Frond** 자체 스파인(중심선)을 가지고, **그 스파인을 따라 면이 펼쳐집니다.** 면 자체가 하나의 긴 리본/날개 형태.

```
Branch ────────────────────
              │
         ─────●─────        ← Frond 스파인
        /     │     \
       /      │      \      ← 스파인을 따라 면이 펼쳐짐
```

---

### 어떤 식생에 쓰이나

| 제너레이터     | 적합한 식생                    |
| --------- | ------------------------- |
| **Leaf**  | 활엽수 잎, 꽃잎, 개별 잎사귀         |
| **Frond** | 고사리 엽상체, 야자수 잎, 잔디, 침엽 다발 |

---

### 가장 중요한 차이 — UV와 형태 제어

**Leaf**는 각 잎이 독립적이라 잎마다 UV가 따로 잡힙니다. 잎 텍스처 1장을 각 포인트에 반복 배치하는 구조입니다.

**Frond**는 스파인 전체가 하나의 연속된 면이라 UV가 스파인 길이를 따라 흐릅니다. 고사리 잎맥처럼 **긴 방향으로 연속된 텍스처**가 필요한 형태에 맞습니다.

```
Leaf UV                Frond UV
┌──┐ ┌──┐ ┌──┐        ┌──────────────┐
│🍃│ │🍃│ │🍃│        │~~~~~~~~~~~~~~│
└──┘ └──┘ └──┘        └──────────────┘
각각 독립              스파인 따라 연속
```

---

### 한 식생 안에서 혼합 사용

실제 작업에서는 둘을 같이 씁니다. 고사리를 예로 들면:

```
Trunk (줄기)
└── Frond (엽상체 전체 형태)
    └── Leaf (엽상체 위의 작은 소엽들)
```

Frond가 큰 틀을 잡고, Leaf가 디테일을 채우는 방식입니다.
