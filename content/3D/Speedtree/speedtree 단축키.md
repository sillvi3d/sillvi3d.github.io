## 뷰포트 탐색 (Tree Window 마우스)

|단축키|기능|
|---|---|
|LMB + 드래그|뷰 회전|
|MMB + 드래그|뷰 패닝|
|LMB + MMB + 드래그|빠른 줌|
|Z|트리 전체가 보이도록 줌 아웃|
|V + 드래그|라이트 방향 회전/틸트|
|G + 드래그|바람 방향 변경|

## 제너레이터 선택 (Tree Window)

| 단축키                | 기능                                |
| ------------------ | --------------------------------- |
| Tab                | Generator / Node / Freehand 모드 전환 |
| Delete / Backspace | 선택한 오브젝트 삭제                       |
| ↑                  | 자식 오브젝트 선택                        |
| ↓                  | 부모 오브젝트 선택                        |
| →                  | 다음 오브젝트 선택                        |
| ←                  | 이전 오브젝트 선택                        |
| F2                 | 선택한 노드/제너레이터 이름 변경                |

## 포커스 (Tree Window)

| 단축키       | 기능                        |
| --------- | ------------------------- |
| ==F==     | 선택한 노드에 포커스 (조상/자손 전체 표시) |
| Shift + F | 선택한 노드 + 형제만 표시, 자손 숨김    |
| Ctrl + F  | 포커스 설정 초기화                |

## 해상도

|단축키|기능|
|---|---|
|D|Tree Window 해상도 낮추기|
|Ctrl + D|Tree Window 해상도 높이기|

## 렌더 모드

|단축키|기능|
|---|---|
|Ctrl + 1|Standard 렌더 모드|
|Ctrl + 2|Scribed 렌더 모드|
|Ctrl + 3|AO 렌더 모드|
|Ctrl + 4|Albedo Check 모드|
|Ctrl + 5|Saturation Check 모드|
|Ctrl + 6|Subsurface Check 모드|
|Ctrl + 7|Lightmap 렌더 모드|

## 가시성 토글 (Tree Window)

|단축키|기능|
|---|---|
|1|Leaf 표시/숨김|
|2|Frond 표시/숨김|
|3|Branch 표시/숨김|
|4|Zone 표시/숨김|
|5|Proxy 표시/숨김|
|6|Forces / Mesh 표시/숨김|
|7|Collision Object 표시/숨김|
|8|Wind 표시/숨김 (바람 On/Off)|
|9|Projector 표시/숨김|
|10|Mesh Helper 표시/숨김|
|` (Backtick)|하이라이팅 토글|

## 노드 숨기기 (Tree Window + Generation Editor 공통)

|단축키|기능|
|---|---|
|H|선택한 노드/제너레이터 숨기기|
|C|자식 노드를 가장 깊은 자손부터 단계적으로 숨기기|
|X|숨겨진 자식 노드를 직계 자식부터 단계적으로 표시|

## 선택 스타일

|단축키|기능|
|---|---|
|~|선택 스타일 표시 토글|
|Shift + ~|선택 스타일 순환|
|Shift + W|와이어프레임 ↔ 아웃라인 선택 스타일 전환|

## 조작 기즈모 (Force / Mesh 대상)

|단축키|기능|
|---|---|
|W|이동 기즈모|
|E|회전 기즈모|
|R|스케일 기즈모|
|Q|기즈모 끄기|

## 서브디비전

|단축키|기능|
|---|---|
|Shift + +|서브디비전 레벨 증가|
|-|서브디비전 레벨 감소|

## 카메라 (Tree Window)

|단축키|기능|
|---|---|
|Shift + >|카메라 리셋|
|Y|씬 오브젝트를 카메라 보는 방향으로 회전|

## Generation Editor

|단축키|기능|
|---|---|
|↑|자식 제너레이터 선택|
|↓|부모 제너레이터 선택|
|→|같은 부모의 오른쪽 제너레이터 선택|
|←|같은 부모의 왼쪽 제너레이터 선택|
|L + Shift + ↓|같은 종류의 제너레이터 전체 선택|
|Ctrl + D|선택한 제너레이터 복제|
|Shift + D|선택한 제너레이터의 모든 자손 선택|
|L|제너레이터 잠금 토글|
|Delete / Backspace|제너레이터 삭제|
|A|Generation Editor 기본 뷰로 복귀|
|F2|이름 변경|
|T|상단으로 이동 (Mesh Converter 전용)|
