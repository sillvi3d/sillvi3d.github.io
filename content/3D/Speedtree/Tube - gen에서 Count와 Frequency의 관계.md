title: Tube - gen에서 Count와 Frequency의 관계
---


Mode가 **Interval** 로 설정되어 있을 때

|파라미터|역할|
|---|---|
|`Frequency`|부모 스파인을 따라 **배치 간격** (0~1 정규화 비율)|
|`Count`|각 배치 지점에서 **동시에 몇 개** 나올지|

Frequency = 40.05라면, 슬라이더 스케일상 실제 값은 **0.4 수준**일 가능성이 높습니다. 0.4면 부모 스파인 길이의 40% 간격으로 하나씩 배치된다는 의미입니다. First=0.05, Last=0.95 범위 안에서 그 간격으로 계산하면 실제 배치 수가 결정됩니다.

4개가 나왔다면:

```
0.05 → 0.30 → 0.55 → 0.80 (→ 0.95에서 마감)
≈ 약 4개 배치
```

Count = 3은 **각 지점에서 3개씩** 나온다는 의미인데, 뷰포트에서 각 노드에서 방사형으로 선이 여러 개 나오는 것이 그것입니다.

---

### First / Last 해석

부모 스파인의 **0~1 정규화 위치**입니다.

```
0 = 부모 스파인의 맨 아래 (뿌리)
1 = 부모 스파인의 맨 위 (끝)

First = 0.05 → 아래에서 5% 지점부터 시작
Last  = 0.95 → 위에서 5% 남기고 끝
```

즉 줄기의 맨 아래와 맨 위 끝부분에는 배치되지 않도록 여백을 주는 설정입니다. 자연스러운 식생에서 줄기 뿌리 바로 위나 끝 꼭지점에는 가지가 잘 안 나오기 때문에 보통 이렇게 약간 여백을 줍니다.

**Clip**은 배치된 것 중 일부를 추가로 제거하는 확률 값입니다.
